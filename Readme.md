# DevTools Fullscreen

![DevTools Fullscreen](icons/icon128.png)

## Описание

**DevTools Fullscreen** — это расширение для браузера Google Chrome, которое автоматически разворачивает окно браузера на весь экран при открытии инструментов разработчика (DevTools). После закрытия DevTools окно возвращается к своему исходному размеру (если оно не было развернуто изначально).

## Функциональные возможности

- Автоматическое разворачивание окна на весь экран при открытии DevTools.
- Возврат окна к исходным размерам после закрытия DevTools (если окно не было развернуто в момент вызова инструментов разработчика).
- Простая интеграция и минимальное вмешательство в работу браузера.

## Установка

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/<your-username>/devtools-fullscreen.git
   ```
2. Откройте Chrome и перейдите на страницу расширений:
   ```
   chrome://extensions
   ```
3. Включите режим разработчика (переключатель в правом верхнем углу).
4. Нажмите **Загрузить распакованное расширение** и выберите папку с проектом.

## Структура проекта

```plaintext

├── background.js         # Логика работы сервисного воркера

│   └── ru/messages.json  # Локализация для русского языка

```

## Локализация

Расширение поддерживает несколько языков. В настоящее время доступны:
- Английский (en)
- Русский (ru)
